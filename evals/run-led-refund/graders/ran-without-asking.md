Judge the final message of a run of an approved plan. PASS if the run went from the plan to a written test
report without stopping mid-run to ask the developer a question that the plan or the rules already settle, and it
ends by handing the report over for acceptance (asking for acceptance is fine). FAIL if it stopped before the
report to ask for a decision, or claims to have accepted, committed or merged anything.
